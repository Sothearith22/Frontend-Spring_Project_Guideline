Six moves to a running service

Each one depends on the last, so run them in order the first time through.

01

Clone the repo

Pull the starter down under your own project name.

git clone https://github.com/Sothearith22/Spring_Folder_Structre.git my-project
02

Open it as a Maven project

IntelliJ and VS Code with the Java extension pack both detect pom.xml automatically and resolve dependencies on open.

03

Configure application.properties

Set your database URL, username, password, and server port before running anything that touches repository/.

spring.datasource.url=jdbc:postgresql://localhost:5432/mydb
04

Install dependencies and build

Pulls everything listed in pom.xml and compiles the project.

mvn clean install
05

Run the app

Or just run DemoApplication.java directly from your IDE.

mvn spring-boot:run
06

Build your first endpoint

Add the pieces in this order — each layer only talks to the one next to it.

entity→ repository→ service→ controller
